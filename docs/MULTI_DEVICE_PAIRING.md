# Multi-device account pairing

Тарифный device_limit теперь имеет реальный серверный контур.

## Модель

Каждое приложение по-прежнему может стартовать анонимно и получить собственный trial-user. Чтобы присоединить второе устройство к оплаченному аккаунту:

1. активное устройство аккаунта создаёт одноразовый pairing code;
2. код действует 10 минут;
3. новое устройство, уже имеющее собственную device identity, предъявляет код подписанным запросом;
4. сервер проверяет device_limit целевого плана;
5. device переносится к целевому user;
6. временный пустой trial-user нового устройства удаляется;
7. pairing code помечается использованным.

## Защиты

- code содержит 64 bits случайности и хранится только как SHA-256;
- код одноразовый;
- claim требует действующую device identity и replay sequence;
- нельзя слить аккаунт, на котором уже есть платежи, подписки или несколько устройств;
- trial имеет limit=1 и pairing code не выдаётся;
- device_limit проверяется транзакционно перед переносом.

## Account status

POST /api/v1/client/account/status возвращает entitlement, план, срок, grace, device_limit и число активных устройств.
