# VPNX3 — план разработки и фактический статус

## Правила разработки

- основная ветка: `main`;
- GitHub Actions/CI не используются;
- каждый спринт должен оставлять проект в логически согласованном состоянии;
- секреты не помещаются в Git;
- сетевой контур отделён от бизнес-логики;
- документ обновляется по факту реализации.

## Спринт 0 — фундамент Control Plane: ЗАВЕРШЁН

Реализованы PostgreSQL, версионные миграции, пул соединений, health/readiness, роли и разрешения, Argon2id для административных паролей, хешированные сессии, первичное создание владельца, append-only аудит, идентификаторы запросов, защитные HTTP-заголовки и контейнерное окружение.

## Спринт 1 — управление нодами: ЗАВЕРШЁН

Реализованы одноразовые коды подключения с хранением только хеша, Node Agent, индивидуальная Ed25519-идентичность нод, подписанные heartbeat-запросы, защита последовательностью от replay, Linux-метрики, конечная машина состояний, publish/drain/maintenance/quarantine/retire, история состояний, автоматическое обнаружение heartbeat timeout и безопасный systemd-установщик с обязательной проверкой SHA-256.

## Спринт 2 — пользовательский доступ / Data Plane: В РАБОТЕ

Уже реализованы:

- анонимная регистрация устройства без обязательного email;
- Ed25519-идентичность устройства;
- 7-дневный пробный период как серверное право;
- последовательность запросов против replay;
- короткоживущий подписанный Access Lease;
- учёт активной подписки и grace-периода;
- отдельный ключ подписи доступа;
- offline-проверка Access Lease на VPN Worker;
- локальный worker authorization service.

Осталось:

1. интерфейс транспортного адаптера;
2. управление сетевыми сессиями;
3. первый стандартный транспорт;
4. выдача и освобождение сетевых адресов;
5. метрики Data Plane;
6. сквозной тест «устройство → lease → worker → туннель».

## Спринт 3 — подписанная конфигурация: ОСНОВА ЗАВЕРШЕНА

Реализованы отдельный ключ конфигурации, версионные манифесты, публикация активных ingress, цифровая подпись, клиентская проверка, срок действия, защита от отката, Last Known Good cache, атомарная запись кеша и fallback.

Следующий уровень: физически независимые зеркала и аварийный корневой манифест.
