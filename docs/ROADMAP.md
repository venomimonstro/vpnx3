# VPNX3 — план разработки

## Правила разработки

- основная ветка: `main`;
- GitHub Actions/CI на текущем этапе не используются;
- каждый этап должен оставлять репозиторий в запускаемом состоянии;
- временные архитектурные решения фиксируются как технический долг;
- секреты не добавляются в Git;
- сетевые и бизнес-компоненты разделяются.
