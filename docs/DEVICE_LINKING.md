# Привязка устройств к одному аккаунту

Проблема: первоначальная anonymous registration создаёт отдельного user для каждого устройства. Это делало plan.device_limit бессмысленным между Android/Chrome/Firefox.

Новая схема:

1. Уже зарегистрированное активное устройство выполняет подписанный POST /api/v1/client/link-code.
2. Сервер проверяет активную подписку и device_limit.
3. Создаётся одноразовый код примерно 64 бит энтропии, сроком на 10 минут.
4. В БД хранится только SHA-256 кода.
5. При создании нового кода предыдущие неиспользованные коды пользователя инвалидируются.
6. Новое устройство генерирует собственную identity key pair.
7. Оно подписывает POST /api/v1/client/register-linked своим новым ключом и передаёт link_code.
8. Сервер снова проверяет device_limit внутри транзакции и создаёт device сразу у существующего user.
9. Код помечается used_at.

Приватные ключи между устройствами не передаются.

Без активной платной подписки лимит считается равным 1, поэтому перенос trial на дополнительные устройства через link code не разрешён.
