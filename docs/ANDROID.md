# Android MVP

Android-клиент реализуется нативно на Kotlin/Jetpack Compose.

## Уже заложено

- AGP 9.4.x;
- встроенная поддержка Kotlin AGP 9;
- Compose;
- Android Keystore;
- ECDSA P-256 identity устройства;
- доказательство владения закрытым ключом;
- анонимная регистрация;
- локальное хранение user/device ID;
- последовательность подписанных запросов;
- получение Access Lease;
- запрос последней конфигурации;
- запрос системного разрешения VPN;
- настоящий Android VpnService как точка интеграции транспорта.

## Ключ устройства

Закрытый identity key не сериализуется приложением. Он создаётся и используется через Android Keystore.

WireGuard-ключ туннеля должен быть отдельным от identity key. Нельзя использовать один криптографический ключ одновременно для идентичности учётного устройства и сетевого транспорта.

## Следующая итерация

1. встроить корневой открытый ключ Configuration Manifest;
2. локально проверять подпись и версию манифеста;
3. хранить Last Known Good configuration;
4. выбрать ingress;
5. создать отдельную WireGuard key pair;
6. запросить worker session;
7. запустить туннель через VpnService;
8. добавить состояния CONNECTING / CONNECTED / RETRYING / DISCONNECTED;
9. foreground notification во время активного VPN.

Текущий VpnTunnelService специально не имитирует соединение до подключения реального транспорта.
