# Первый транспорт Data Plane: WireGuard

WireGuard используется как первый стандартный транспорт для проверки полного жизненного цикла VPN-сессии. Он **не является единственным транспортом архитектуры**.

## Разделение обязанностей

```text
Access Lease
   ↓
Session Manager
   ├── проверяет право
   ├── выделяет адрес
   └── вызывает Transport Adapter
             ↓
       WireGuard Adapter
             ↓
        wg0 / wgctrl
```

Transport Adapter не знает про тарифы и платежи. Session Manager не знает деталей конфигурации WireGuard.

## Предварительная настройка worker

На Linux должен существовать интерфейс WireGuard, например `wg0`, с серверным закрытым ключом, адресом gateway и разрешённой пересылкой пакетов. Закрытый ключ сервера не передаётся Control Plane.

Worker получает только:

- открытый ключ подписи Access Lease;
- имя WireGuard-интерфейса;
- локальный пул клиентских адресов;
- публичный endpoint WireGuard.

## Ограничение текущего спринта

При перезапуске worker локальные сессии создаются заново клиентами. Это сознательное поведение первого транспорта: клиент обязан уметь переподключаться. Постоянное восстановление сессий и несколько транспортов добавляются позже.
