# Android kill switch

VPNX3 использует штатный Android механизм Always-on VPN / lockdown вместо отдельного самописного watchdog.

Приложение открывает системный экран VPN settings. Пользователь может включить:
- Always-on VPN;
- блокировку соединений без VPN (если поддерживается прошивкой).

Это предпочтительно, потому что именно Android OS контролирует сетевой стек при рестарте приложения, Doze и process death.

Pairing-code cleanup: использованные или просроченные коды старше 24 часов удаляются отдельным hourly cleaner.
