# Восстановление состояния VPN Worker

Worker сохраняет минимальное локальное состояние активных сессий в атомарно заменяемом файле `sessions.json`.

Сохраняются только данные, необходимые для восстановления транспортного peer:

- идентификатор сессии;
- идентификатор устройства;
- публичный ключ клиента;
- назначенный внутренний IP;
- срок действия;
- транспортная конфигурация.

Пароли, платёжные данные, закрытые ключи устройства и центральные секреты в этом файле отсутствуют.

При старте worker:

1. проверяет локальный WireGuard-интерфейс;
2. читает сохранённое состояние;
3. отбрасывает истёкшие сессии;
4. резервирует прежние адреса в IPAM;
5. идемпотентно восстанавливает WireGuard peer;
6. перезаписывает очищенный снимок;
7. только после успешного восстановления начинает обслуживать локальный API.

Если восстановить активную сессию невозможно, worker не начинает работу как «здоровый». Это предотвращает расхождение между локальной моделью сессий и фактической конфигурацией транспорта.
