# Admin login throttling

Административный логин защищён persistent rate-limit по паре `normalized email + source IP`.

Правила:

- окно: 15 минут;
- после 8 неудачных попыток с одного IP для одного email вход с этой пары блокируется на 15 минут;
- успешный вход очищает только свою пару email/IP;
- другой IP не блокируется, поэтому злоумышленник с одного адреса не может глобально заблокировать владельца;
- ответ для неправильного email и неправильного пароля одинаковый;
- минимальная задержка неудачного ответа сохраняется;
- throttle state хранится в PostgreSQL и переживает рестарт Control Plane;
- устаревшие записи очищаются фоновым cleaner.

Это не заменяет внешний reverse-proxy/WAF rate-limit, а является вторым уровнем защиты внутри приложения.
