# Сетевые точки нод

Адрес ноды отделён от адресов её публичных сервисов. Это позволяет менять порты, IP и транспорт без обновления приложения.

Типы:

- `session_api` — только HTTPS, выдача транспортной сессии;
- `wireguard` — только UDP/WireGuard;
- `ingress` — HTTPS-точка входного слоя.

Подписанный манифест содержит точки только активных нод. Для worker можно одновременно опубликовать HTTPS session API и UDP WireGuard endpoint. Клиент выбирает адреса из подписанного манифеста, а не из APK.
