# Billing core

Billing разделён на две части.

## Provider adapter

Конкретный эквайер обязан реализовать интерфейс `billing.Provider` и выполнить:

1. проверку криптографической подписи webhook;
2. проверку timestamp/anti-replay по правилам провайдера;
3. разбор provider payload;
4. преобразование в `NormalizedEvent`.

Непроверенный payload не передаётся в Billing Core.

## Billing Core

После проверки провайдером общий код:

- дедуплицирует событие по `provider + provider_event_id`;
- хранит SHA-256 исходного payload;
- идемпотентно обновляет payment;
- при `succeeded` транзакционно создаёт или продлевает подписку;
- учитывает billing period и grace period версии тарифа.

Повторная доставка одного webhook не продлевает подписку повторно.

Тарифы версионируются: изменение цены создаёт новую версию, а старые платежи и подписки продолжают ссылаться на прежний plan_id.
