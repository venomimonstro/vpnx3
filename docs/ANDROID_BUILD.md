# Сборка Android

Для сборки должны быть заданы два значения, которые не хранятся в исходном коде:

```properties
VPNX3_CONTROL_URL=https://<bootstrap-control-endpoint>
VPNX3_CONFIG_PUBLIC_KEY=<base64url-ed25519-public-key>
```

Их можно передать через пользовательский `~/.gradle/gradle.properties` либо параметры сборочной среды.

`VPNX3_CONFIG_PUBLIC_KEY` является закреплённым корнем доверия текущего Configuration Signing Key. Клиент не должен автоматически доверять ключу, полученному по тому же сетевому соединению, которое он пытается проверить.

В дальнейшем для безопасной ротации ключей необходимо перейти от одного operational key к корневому офлайн-ключу и подписанному набору разрешённых configuration keys.

## Проверка конфигурации

Android:

1. получает JSON envelope;
2. Base64URL-декодирует точные подписанные байты payload;
3. проверяет Ed25519-подпись через Tink;
4. проверяет key_id;
5. проверяет версию и запрет отката;
6. проверяет срок действия;
7. только после этого разбирает список ingress;
8. сохраняет envelope как Last Known Good.

Если сеть или Config API недоступны, используется только ранее проверенная и ещё не просроченная конфигурация.
