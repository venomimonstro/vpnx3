# Перенос уже зарегистрированного устройства

Поскольку клиенты выполняют anonymous registration автоматически, устройство может уже иметь временный user до того, как пользователь решит связать его с платной учётной записью.

POST /api/v1/client/redeem-link-code:

- подписывается текущей device identity;
- использует replay sequence;
- проверяет одноразовый link code;
- блокирует target user и device limit в транзакции;
- переносит device на target user;
- удаляет trial dates временного аккаунта;
- помечает code used;
- удаляет пустой source user.

Перенос запрещён, если source user:
- имеет больше одного устройства;
- имеет payments;
- имеет subscriptions.

Так платный аккаунт нельзя случайно слить с другим платным аккаунтом и потерять финансовую историю.
