# VPNX3

Распределённая VPN-платформа с централизованным управлением, автоматическим подключением узлов, подписанной удалённой конфигурацией, отказоустойчивой сетевой архитектурой и собственными клиентскими приложениями.

## Статус

Проект находится на этапе Foundation / Control Plane.

Основной концепт и техническое задание: `docs/CONCEPT.md`.

## Принципы

- отсутствие единой точки отказа;
- отдельные контуры управления и пользовательского трафика;
- заменяемые узлы, поставщики и транспортные механизмы;
- подписанная удалённая конфигурация;
- минимизация чувствительных журналов;
- поэтапная разработка без зависимости от GitHub Actions;
- все изменения ведутся в `main`.

## Первый этап разработки

1. базовый Control Plane;
2. PostgreSQL;
3. роли и аудит;
4. служба управления узлами;
5. подписанная конфигурация;
6. далее — Node Agent и VPN Data Plane.
